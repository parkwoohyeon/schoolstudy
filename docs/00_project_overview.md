# AI Sentiment Analyzer - Project Overview

## 프로젝트 소개
사용자가 텍스트를 입력하면 AI가 감정을 분석하여
긍정 / 부정 / 중립 결과를 제공하는 웹 서비스.

---

## 프로젝트 목표
- OpenAI API 기반 감성 분석 서비스 제작
- Apple 스타일 미니멀 UI 구현
- Frontend + Backend 구조 학습
- Supabase 연동 경험
- 실제 배포 경험(Vercel)

---

## 핵심 기능
1. 텍스트 입력
2. 감성 분석 요청
3. OpenAI API 호출
4. 감성 결과 반환
5. 결과 모달 출력
6. 신뢰도 표시
7. 분석 이유 출력

---

## 사용자 흐름
1. 사용자 텍스트 입력
2. 감성분석 버튼 클릭
3. 백엔드 API 요청
4. OpenAI 분석 수행
5. 결과 반환
6. 모달 출력
